## 2. Media Optimization & Handling Rules
1. **Lazy Loading**: `loading="lazy"` on all gallery and secondary section images.
2. **Aspect Ratios**: Constrained with Tailwind `aspect-video`, `aspect-[4/3]`, and `aspect-square`.
3. **Cross-Origin & Referrer Policy**: Configured with `referrerPolicy="no-referrer"` to prevent sandbox blocking.
4. **Fallback Handling**: Graceful fallback containers rendering institutional gradients and vector badges.
